# VIROX — Blueprint Build (React + Vite)

This project is a blueprint implementation of **VIROX**:

- Dashboard with multi-channel metrics and revenue snapshot
- Platform/content campaign builder with Paste Link → Auto Detect
- Goal/intent, quantity, RPM target, service level, and ad view scheduling controls
- Safe automation simulation modules (promotion engine, offline queue, baton multi-tasking)
- LivePulse chat assistant view
- Guidance/coaching recommendations
- Analytics and monetization pages

## Run

```bash
npm install
npm run dev
```

> Note: This implementation is UI/state simulation and planning support. It does not execute platform policy-violating automation.
